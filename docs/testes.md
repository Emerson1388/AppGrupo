# Testes

```bash
npm test
npm run build
npm run lint
```

Os testes unitários desligam o Supabase (`vite.config.ts` `test.env`) para cobrir o modo demo local.

## Manual (obrigatório após o SQL)

1. Cadastro no notebook → login.
2. Login no celular com o mesmo e-mail/senha.
3. Alterar perfil no celular → recarregar no notebook.
4. Criar treino (admin) → aparece na agenda do outro aparelho.
5. Confirmar presença / check-in / post / curtida cruzando os aparelhos.
